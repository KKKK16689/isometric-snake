## 1. 背景与目标

现状：单 HTML 文件（约 600 行）的等距视角贪吃蛇，含 4 种模式（简单 / 普通 / 双人 / 人机三档）、冲刺能量系统、洪水填充 AI、夜间霓虹主题、WebAudio 合成音效、lowFx 自动降级。

定位：先做「面向玩家的好玩好看」（B），未来转型「作品集展示」（A）。

### 1.1 本轮范围（做）

1. **C1 主题皮肤**：从 1 套固定夜间主题升级为 10 套数据驱动主题，可切换、可记忆
2. **C2 粒子动效**：新增对象池化粒子系统（吃食爆炸、冲刺拖尾、撞击火花、胜利烟花、食物光晕），沿用 lowFx 降级机制
3. **C3 音乐音效**：在现有合成音效基础上补充（冲刺呼啸、胜/败旋律、可选琶音 BGM 默认关），音量状态记忆
4. **架构重构**：单文件拆分为 `src/` 多源文件 + 无依赖打包脚本 `build.js` → `dist/index.html`
5. **发布准备**：README 中英双语更新、screenshot、LICENSE作者名、GitHub 仓库与 Pages

### 1.2 本轮范围（不做，仅留钩子）

- A 道具系统（护盾 / 加速 / 减速陷阱 / 金苹果）
- D 留存玩法（排行榜 / 每日挑战）
- AI 算法改动或文档化
- 新玩法模式

**钩子契约**：新增道具/玩法时只能改动 `core.js`（逻辑）与对应组件，不得破坏现有组件边界（见 §5）。

## 2. 功能规格

### 2.1 主题系统

**设计原则（对应用户「方便以后更新」要求）**：主题 = 纯数据对象，注册表驱动。新增主题只做「数组里追加一个对象」，零逻辑改动。

**主题数据结构**（唯一数据源，定义于 `src/js/themes.js`）：

```js
// 仅示意契约，实现时按此形状落地
{
  id: 'neon-night',            // 唯一标识，用于 localStorage 与 data-theme
  name: '霓虹夜',              // UI 显示名
  css: { bg, fg, muted, f1, f2, edge, btn },   // 覆盖 UI 的 7 个 CSS 变量
  canvas: {                    // Canvas 渲染调色板（render.js 只读此对象，不写死颜色）
    floorTop, floorLeft, floorRight,  // 等距方块三面
    grid,                      // 地板网格线颜色（rgba）
    glow,                      // 发光/描边主色
    food,                      // 食物主色
    star,                      // 星空颜色；null = 无星空（亮色主题）
    spark                      // 粒子/火花强调色
  }
}
```

**切换与持久化**：

- UI：模式栏下新增一行「主题色点」：10 个圆点，底色 = 该主题 `css.bg`，悬停显示名称；当前主题描边高亮。复用现有皮肤选择点（`.sw .dot`）的样式语言
- 点击切换：立即应用（CSS 变量注入 + canvas 调色板引用替换 + `<meta name="theme-color">` 同步为主题 bg），无需重载；对局进行中切换同样即时生效（仅重建地板离屏缓存），不打断游戏
- 记忆：localStorage `snake.theme`；失效/非法值回退默认霓虹夜
- 蛇皮肤（SK 数组 6 色）属于玩家身份标识，不随主题变化，维持现状

**CSS 变量注入方式**：`base.css` 的 `:root` 内置默认（霓虹夜）变量兜底（JS 未运行时首屏即默认主题）；切换主题时由 `themes.js` 通过 `document.documentElement.style` 覆盖同名变量。删除现版 `prefers-color-scheme` 自动暗色块、`:root[data-theme="dark"]` 与 `html:root:root:root` 强制覆盖 hack（已被主题系统取代）。

### 2.2 粒子系统

**架构**：`src/js/particles.js`，固定容量对象池（容量 256，超限丢弃最旧粒子），不产生 GC 压力。

**粒子形状**：小方块（与等距世界语言一致，也可用圆点），带重力/阻尼/寿命/颜色，按 `x + y` 与场景同序绘制，保证遮挡正确。

**效果清单**（事件 → 效果 → lowFx 行为）：

| 事件 | 效果 | 参数 | lowFx 时 |
|------|------|------|----------|
| 吃食 | 爆炸 | 12 粒，food+spark 色 | 减半 |
| 冲刺中 | 拖尾 | 每帧沿蛇身 1-2 粒，spark 色，短寿命 | 关闭（保留现版电弧） |
| 撞击死亡 | 火花 | 20 粒，向四周喷溅 | 减半 |
| 对战获胜 | 烟花 | 3 轮 × 14 粒，多种 spark 衍生色 | 1 轮 |
| 食物常驻 | 光晕 | 食物处径向渐变压呼吸（非粒子，直接绘制） | 关闭 |

**与现有系统的关系**：现版已有「吃食粒子 + 冲刺电弧/光轨」，迁移进新粒子模块并补齐清单内其余效果；电弧保留在 render.js，不属于粒子池。

### 2.3 音乐音效

**架构**：`src/js/audio.js`，全部 WebAudio 振荡器/噪声即时合成，**不引入任何音频资源文件**（维持零资源原则）。

| 音效 | 合成方式 |
|------|----------|
| 吃食 | 正弦短促音，基础音高随连击数升调（阶梯上限后循环） |
| 冲刺 | 滤波噪声扫频（呼啸），冲刺期间循环播放 |
| 撞击 | 白噪声短脉冲 + 低通 |
| 获胜 | 上行大三和弦三连音 |
| 失败 | 下行双音 |
| BGM | 轻柔琶音循环（三角波、低增益、约 90 BPM），**默认关闭**，独立开关 |

**控制与持久化**：

- UI：「音效 开/关」维持现按钮；新增「音乐 开/关」按钮（默认关）
- 记忆：localStorage 记录两个开关状态
- AudioContext 手势解锁：首个 `pointerdown`/`keydown`/`touchstart` 时创建并 `resume()`；不支持 WebAudio 的浏览器整体静默降级（全部调用 no-op）

### 2.4 架构重构

**目录**（`d:\WorkBuddy\贪吃蛇`）：

```
index.html                # 打包前：保留现单文件版可直接玩（基线，首 commit 留存）
src/
  index.html              # 源模板：结构 + <link>/<script> 引用
  css/base.css            # 布局与组件样式（迁移现 <style>，颜色全部走 CSS 变量）
  js/core.js              # 常量、模式配置、游戏循环、碰撞/吃食/胜负逻辑、事件总线
  js/render.js            # canvas 等距渲染、画家算法排序、离屏地板缓存、电弧
  js/ai.js                # AI（原样迁移，不改算法）
  js/themes.js            # 主题注册表 + 应用/切换/持久化
  js/particles.js         # 粒子对象池与各效果
  js/audio.js             # 合成音效 + BGM + 音量状态
  js/input.js             # 键盘 / 触屏按钮 / 滑动 / 暂停
build.js                  # Node 无依赖打包脚本
dist/index.html           # 打包成品（发布与交付用）
README.md / LICENSE / screenshot.png .gitignore
docs/superpowers/specs/    # 本设计文档
docs/v1.0-等距贪吃蛇-人机对战.html   # 旧版备份（git 历史同时留底）
```

**加载方式**：src 下使用**经典（非 module）`<script>` 顺序加载**，按 `core → themes → audio → particles → render → ai → input → main(引导)` 的顺序排 `<script>` 标签。**不用 ES module**——`file://` 直开 src/index.html 会因 CORS 失败；经典脚本保证「双击即可开发调试」，与产品零依赖原则一致。各文件挂到统一全局命名空间（如 `window.Snake`），模块间只通过该命名空间与事件总线通信。

**build.js 打包**：无第三方依赖的 Node 脚本，读 `src/index.html`，把 `<link rel="stylesheet">` 与 `<script src>` 按声明顺序内联为单文件，输出 `dist/index.html`。文件缺失时打印点名错误。产物行为与 src 版一致（发布前走查验证，见 §6）。

## 3. 数据流

```text
用户输入 (键盘/触屏/滑动)      UI 事件 (模式/主题/音效按钮)
        │                            │
        ▼                            ▼
     input.js ──────────────►  core.js (状态 + tick 循环 + 事件总线 emit)
        │                            │
        │            eat / dashOn / dashOff / crash / win / gameOver / tick
        ▼                            ▼
   core 内部更新蛇、食物、能量    ┌────────────┬─────────────┬────────────┐
                                 ▼            ▼             ▼            ▼
                            render.js   particles.js   audio.js   themes.js
                            (读状态绘制) (听事件出特效)  (听事件发音) (管理主题)
```

- **事件总线**：core.js 内置极简 pub/sub（`bus.on/off/emit`）；系统间**单向依赖**——core 不 import 任何表现层模块；render / particles / audio 只订阅事件与读状态，互不调用；themes 只被 core 引导调用一次（`theme.init()`），其余模块经 `Snake.theme.current` 只读取色
- **主题热切换**：`theme.apply(id)` → 更新 CSS 变量 + `Snake.theme.current` 引用替换 + 通知 render 清理离屏地板缓存（重新按新调色板绘制）

## 4. 错误处理与边界

| 场景 | 处理 |
|------|------|
| localStorage 不可用（隐私模式/配额 0） | 统一 `safeGet/safeSet` 包装 try/catch，失败降级为内存存储（仅本次会话），游戏不中断 |
| 主题 id 非法或数据缺失 | 回退默认霓虹夜，console.warn |
| AudioContext 未解锁/不支持 | 全部音频调用 no-op；手势后自动 resume |
| 粒子池满 | 丢弃最旧粒子，不报错 |
| lowFx 触发 | 各效果按 §2.2 表降级/关闭，渲染循环不中断 |
| build.js 文件缺失 | 打印缺失文件名并以非零码退出 |

## 5. 组件边界（防回归契约）

| 组件 | 职责唯一 | 禁止 |
|------|----------|------|
| core.js | 游戏规则、状态、tick、事件 | 不碰 DOM/CSS/音频/粒子 |
| render.js | 一切 canvas 绘制 | 不改游戏状态（只读） |
| ai.js | 蛇 2 的控制决策 | 不读 UI、不改渲染 |
| themes.js | 主题数据 + 应用 | 不含绘制逻辑 |
| particles.js | 粒子池与效果 | 不改游戏状态 |
| audio.js | 发声 | 不改游戏状态 |
| input.js | 输入归一化为方向指令 | 不直接改渲染/音频 |

未来加道具（A）/留存（D）只应触碰 core.js 与新增组件。
