1. 确认软件全称、版本、申请人信息与真实开发/发表日期；不要把计划日期写成完成日期。
2. 核对所有实际贡献者、AI 协助记录、外部代码/图片/音符序列来源；补充存在的授权或合作约定。

4. 用根目录 index.html 实际操作：主页 → 方向练习 → 港口航线 → 设置/暂停 → 完成/重试；补手机真机截图与浏览器型号。

## 后续工程边界（P2）

启动模板先载 core，再载 levels/terrain，随后主题/图案/声音/粒子/render/ai/input，最后 experience 初始化主页。核心运行时通过 Snake 全局获取层图与关卡，不是严格无耦合模块系统。

- core 管理规则，但 render 会写 frameDt/lowFx/特效等状态，input 和 experience 也读写偏好与表现状态。后续按逻辑状态/表现状态划定接口再拆，不在本轮迁移成 ES module，以免破坏 file:// 双击运行。
- 幽灵存档只记录 x/y，未携带层高、规则版本和地形身份校验；后续采用版本化数据与显式旧档兼容，不直接覆盖现有记录。
- AI 在特殊地面和传送门的规划仍采用保守策略；地形 AI 当前关闭冲刺，不能将 README 的经典竞速描述当作地形功能已开放。
- 冰面/运输带当前一次移动仅结算首个途经普通食物；多食物地图需新增多拾取与增长语义的回归后处理。落点提示只预览下一格，不能当作整段特殊地面的安全保证。
- 对话框当前有初始焦点及 inert 背景，键盘焦点循环与触控读屏仍需专项检查；手机 Safari、刘海安全区、音频解锁、真实多点触控均留待真机验收。
