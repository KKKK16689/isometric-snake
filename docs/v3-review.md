## 方案与边界

采用定点修复 + 行为测试：SW 保留导航网络优先、资源 SWR；输入跟踪首个有效指针；退出游玩时通过已有 sprintOff 事件停止冲刺。复用现有 Canvas 与源码打包方式。

另外两种做法：仅改缓存过滤最省改动，但遗漏无缓存和触屏失败；重写模块/图片地图能够扩展视觉，但引入渲染、离线和权属风险。本轮不选。用户已授权按优先级实施，本方案不新增玩法、提交或发布动作。
