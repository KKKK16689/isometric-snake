# 等距贪吃蛇 V3.0.0 · 用户说明

作者：孔垂瑞

## 运行环境

使用支持 Canvas 2D 的现代电脑或手机浏览器。联网打开 GitHub Pages；成功缓存游戏壳后可离线游玩。单独下载根目录 index.html 也可打开，安装到主屏幕和 Service Worker 需要 HTTP(S) 环境。

## 开始游玩

主页提供港口航线、经典练手、自由探索、挑战 CR 和双人对战。选好玩法后点击“开始”，或按方向键开始。设置可选择普通难度、地图、音效、主题、每日挑战及落点提示；更换模式或地图会重置当前对局。

## 方向与冲刺

| 键盘 | 触屏箭头 | 棋盘方向 |
| --- | --- | --- |
| W / ↑ | ↗ | 右上 |
| D / → | ↘ | 右下 |
| S / ↓ | ↙ | 左下 |
| A / ← | ↖ | 左上 |

不允许直接掉头；连续输入最多排队两次转向。同屏双人时 P1 使用 WASD、E/左 Shift 冲刺，P2 使用方向键、Enter/右 Shift/斜杠冲刺。单人模式也可以在棋盘滑动转向。冲刺需按住，能量归零会锁定，回充至 30 后解锁。

主页“方向练习”提供五步互动训练，四个方向各走一步后按住冲刺半秒。练习独立于对局，无碰撞损失。

## 港口航线

依次吃到六个带编号的航标：码头补给 → 桥下通行 → 登上桥面 → 跨越水渠 → 高台观测 → 返回东港。目标进度、提示与用时显示在左上，小地图的食物点是当前目标。

桥下航标位于地面层，不能从桥面吃到。登桥需要绕到两端的低台阶；跨水桥需要通过台阶进入，水面不可走。高差超过一层不能直接通过。三个生命全部耗尽后结束；重试从第一航标开始。通关最佳用时保存在当前浏览器。

## 对局与反馈

“落点提示”只标出已排队方向的下一格；红色表示当前存在障碍。它不替代路线规划，不预测对手或特殊地面的整段运动。撞到自身、对手、墙、水、关闭闸门或不可跨越高差，会显示对应原因。运输带和冰面途中也检查身体碰撞。

顶部“暂停”或空格/P 控制暂停；设置、主页、练习及切后台会暂停。关闭面板后通过“继续”恢复。“重来”立即将当前玩法重置到待开始状态。航线时间和地形闸门随有效游戏时间推进。

暂停、重开、掉命及结算会结束冲刺；恢复后需要重新按住冲刺键。触屏手势只跟踪首先按下的一根手指，手势被系统取消后不会继续转向；练习中切后台会取消半秒冲刺计时。

## 版本与记录

当前版本 V3.0.0，作者孔垂瑞。经典最高分、各地形模式记录与航线通关记录相互分开。记录只存在本机；浏览器禁用存储时仍可游玩，但无法保证保存。历史入口 legacy/ 和 legacy20/ 保留原版本。
