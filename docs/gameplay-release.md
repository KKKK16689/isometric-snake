# V3.0.0 玩法与操作完善

作者及版权署名：孔垂瑞。版本日期：2026-11-06。

## 变化

- 新增紧凑港口图和六航标任务，包含同格桥上桥下、跨水桥、台阶与高台。通过真实转向序列可在三条命均保留的情况下通关。
- 新增主页入口、独立五步方向练习、暂停/重来操作、可关闭的下一格提示、死亡原因与本机通关最佳时间。
- 修复选择器在每次开关地形时重复注册、URL 地形入口不显示地图选项、换图混用旧蛇身与新层图。
- 修复冰面/运输带中途身体碰撞和途经金苹果拾取；重生清理传送门冷却。
- 暂停冻结闸门相位、航线计时、连击与金苹果计时；失焦清除冲刺并暂停；选择框键盘操作与重复 keydown 不再污染转向队列。
- 当前软件版本、包信息、分享文案、诊断标记与作者展示保持一致；旧归档和原有提交历史保持原样。

## 架构和存储

core.js 管理规则与进度；levels.js 管理地图和任务数据；experience.js 管理主页、状态对话框及独立练习；input.js 统一输入；render.js 保留 Canvas 绘制。无需新运行依赖。

任务进度键：iso-snake-progress-v1。任务最高分与录像使用独立 mission 命名空间。原有最高分和偏好键保持兼容。版本使用 package.json、core.js 和页面元数据，并由一致性测试检查；页面由 node build.js 生成。

## 验证

npm test 包含经典行为及视觉摘要、渲染预算、地形连通性、AI 批量对局、SW 离线策略、任务逐格通关、桥上下层提示、途中碰撞、切图重置与输入防误触。浏览器另检查主页、练习、航线入口、设置暂停与恢复；手机真机的多点触控和音频体验仍应由作者实际试玩。
